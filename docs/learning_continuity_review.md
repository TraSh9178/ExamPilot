## 1. 材料与学习范围恢复

课程 JSON 新增可选 learning_state 字段，兼容没有该字段的旧课程，不需要新建数据库表。
材料、范围、审核状态和练习顺序随原有课程／成绩事务一起保存，失败全部回滚。

保存的材料只包含提取文本、文件名及来源页信息；不保存原始 PDF、PPTX 或图片字节。
文本最多 50,000 字符，页面文本合计最多 50,000 字符，最多 1,000 页；
learning_state 总计最多 512,000 UTF-8 字节。超限返回失败，不悄悄截断或丢弃材料。
登录恢复后可以继续使用原文引用和已确认范围。确认范围时自动尝试保存；失败时侧栏提示待保存。
页面上明确说明材料会随账号保存。

Study Plan → Saved course material 提供带确认的 Delete saved material。
删除失败保留本地材料；删除成功保留课程、题目、成绩和范围，云端材料字段置空。
它不等于删除课程，也不会撤回之前发送给 AI 服务的内容。
匿名会话的操作仅在本地生效，正式站点仍由账号认证控制访问。

## 3. 掌握度证据

总答题数和总正确率仍显示每次已评分练习。
掌握度改用至少 3 个不同题目家族，每个家族只取所选模式下最近一次作答。
重复练习同一题、旧题与修改后的版本不会增加独立题目数量。
Mock Exam 与 Topic Practice 分开计算；错误与未答都会进入证据。

最近一次按照实际练习顺序确定。顺序随课程保存并在恢复时重新应用，
避免批量保存时相同数据库时间戳／随机 UUID 顺序改变掌握度。
旧课程没有顺序记录时沿用数据库既有顺序；无法追溯的真实作答时间不会被编造。
颜色阈值仍为 <60% Weak、60–79.99% Developing、≥80% Mastered，
但这是练习证据指标，不是经过教育学验证的能力认证，也没有新增时间衰减或题目难度模型。

## 2. 题目人工审核与版本

新生成题目进入 pending 状态，旧题保留，新的候选题不会覆盖题库。
Study Plan → Review and edit questions 可以核对题目、四个选项、正确答案和解析，
保存 Approve 或 Flag as problematic。
pending、flagged 和 superseded 题目不会进入新练习、错题重练或 Anki 导出。
已存在但没有审核记录的题目标为 legacy，保持可用，不虚称已经人工批准。

仅改变审核状态不改题目内容。修改题干、选项、答案或解析会追加新 UUID 和 version_of，
旧版本保留并标记 superseded，既有成绩仍对应原题；修订题也不算新的独立掌握度证据。
题目主题与来源页码在此次编辑器中保持不变，编辑后需核对原材料；
生成器不能声明历史版本关系，不能复用旧 ID 改写内容。

审核决定和版本随课程保存。保存失败保留本地编辑并提示重试；
本地尚未保存的编辑仍可能随浏览器刷新丢失，提示不表示已经写入账号。

## 审核路径

1. 用小材料生成课程并确认范围，保存，退出再登录，核对原文和范围。
2. 在 Review and edit questions 批准一题，再进入 Practice；未批准题不得出现。
3. 标记一题为问题题，确认新练习／Anki 中排除；修改另一题，确认旧成绩未变。
4. 多次重练同一题，查看 Progress 的独立题目数仍为 1，状态保持证据不足。
5. 删除 Saved course material，再次登录确认材料不再恢复，课程和成绩仍在。
