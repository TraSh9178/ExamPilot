# Knowledge Map：轻量知识网络

分支 feature/knowledge-map-guidance 基于已提交的数据库改进 8a6b062。

- 小圆点、细灰线、直接显示主题名，节点大小轻微反映连接数量；颜色继续表示实际掌握状态。
- 使用自然力导向布局，初次展开可见自然运动，阻尼逐渐稳定；移除持续运动、边缘反弹与无约束持续漂移。
- 拖动节点时相邻节点随连接弹性调整，松手后逐渐稳定；平移和缩放保留；选择主题后突出邻居，淡化其他节点。
- 点空白取消选择，点主题在右侧显示 Summary、来源、学习进度和已有的前置／后续／相关主题。
- Find a topic 支持键盘搜索；Local graph 只展示该主题的一跳邻居，原课程数据不变。
- 图里默认不显示箭头和连线文字，关系方向在右侧明确显示；悬停连线可查看类型。
- 不自动生成关系，不合并不同课程，不因布局或邻居颜色推断掌握程度。示例课程只有三个主题时图中也只有三个节点。

审核：打开 Calculus I Demo → Knowledge Map，观察初次布局停止；拖动节点后相邻节点应弹性调整并逐渐稳定。
点击节点核对右侧简介，再点空白；选择 Find a topic 并打开 Local graph，检查只留下相邻主题。
搜索框与画布点选同步，点空白取消选择。

图组件目前仍使用现有固定版本 vis-network CDN；无网络时会显示加载提示。
GitHub 同步仍由用户审核后手动完成。

浏览器真实节点点击打开 Summary，点空白清除选择；初次布局与拖动使用阻尼力模拟，稳定后无边缘反弹；搜索与一跳局部图已验证。
